# 公开包范围与许可

本目录是独立发布候选源码，不能与私人研习工作区混装上传。

包括：本项目原创统一 Skill、路由和检索脚本、自包含配置、安装与打包工具、授权本地导入器、可迁移测试、两条合成演示数据。其代码与文档采用 MIT；合成数据没有医家原话或医学断言。

不包括：第三方仓库审计快照、课程短引、课程时间戳库、书籍/医案转录、现有 SQLite 知识库、全局配置和 Skill 清单、聊天状态、个人目录、私人测试日志。没有复制上游安装器、审计脚本或原始课程文件。

原研习版的历史资料存在许可缺失、声明矛盾、非商业限制或原作权利未厘清的情况，因此本公开包不再分发这些资料；这不是断言所有上游资料都禁止再分发。公开代码许可证不改变任何第三方资料的权利。用户另行导入时需要自行确认适用许可、隐私及当地要求。

PUBLIC_FILES.json 是审查后的公开文件清单及 SHA-256。安装和 ZIP 打包都使用白名单，避免误把本地新增语料复制给别人。扫描器另检查常见个人绝对路径、邮箱、私钥文本；它不能保证发现所有秘密，不能代替人工审查。

默认演示库没有足够资料回答医学问题。模式切换、检索运行成功与医学证据充分是不同条件；请保持这种区分，不把候选版宣传为诊疗系统、全量医家知识库或已验证的临床产品。

GitHub 上传和公开发布均不由这些脚本执行。维护者如需上传，应以本公开目录为仓库根，并在上传前复查文件清单和测试。不要把整个私人研习工作区作为仓库根。

Codex 加载方式参照 [官方 Skill 文档](https://learn.chatgpt.com/docs/build-skills)。本包提供原生 Skill 目录供项目使用；未声明已上架官方插件市场，也未验证所有第三方 Agent 平台。
